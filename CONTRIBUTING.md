# Contributing

This repository is a read-only snapshot intended for reference. If you are the owner and want to update files, follow these steps:

1. Make edits locally under the `researchpaper/` folder.
2. Run `push_to_github.cmd` (manual) or `push_to_github_auto.cmd` (requires GitHub CLI and gh auth).
3. Create a release and attach `submission_bundle.zip` so reviewers can download the supplementary materials.

If you are not the owner, do not attempt to push changes to the main repository—contact the owner for permission.
